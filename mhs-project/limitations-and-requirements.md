# Project Limitations and Requirements

## 🚫 What I Cannot Do

### External Service Setup
I **cannot directly**:
- Create Sanity.io accounts or projects for you
- Set up Vercel accounts or connect GitHub repositories
- Configure Cloudflare DNS settings or create accounts
- Purchase domains or manage domain registrations
- Set up GitHub repositories (you'll need to do this manually)
- Configure external webhooks or API keys

### System-Level Operations
I **cannot**:
- Install Node.js or npm on your system (if not already installed)
- Modify your system's global configurations
- Access external APIs or services directly
- Run commands that require elevated privileges

### Real-Time Services
I **cannot**:
- Monitor live website performance
- Receive real-time webhook notifications
- Access live analytics data
- Perform live security scans

## ✅ What You Need to Declare/Prepare Before Starting

### 1. System Requirements
```bash
node --version  # Should be 18.17.0 or higher
npm --version   # Should be 9.0.0 or higher
```

### 2. Account Preparations (Free Tiers)
- **GitHub account** - For version control and CI/CD
- **Vercel account** - For hosting (can sign up with GitHub)
- **Sanity.io account** - For CMS (can sign up with GitHub)
- **Cloudflare account** - For CDN and security (optional initially)

### 3. Project Decisions
**Please specify:**
- **Project name** (for package.json and repository)
- **Domain name** (if you have one, or we can use Vercel's free subdomain)
- **Brand colors/theme** preferences
- **Content structure** preferences (what sections you want)

### 4. Content Planning
**Consider preparing:**
- Company/project logo and images
- Hero section content (headline, description)
- Feature descriptions
- Contact information
- Social media links

### 5. Optional Preparations
- **Google Analytics ID** (if you want analytics)
- **Font preferences** (Google Fonts)
- **Specific design inspirations** or wireframes

## 🎯 Recommended Starting Approach

**Option 1: Start with Code First**
- I create the complete Next.js project structure
- You handle external service setups later
- We use placeholder content initially

**Option 2: Guided Setup**
- I provide step-by-step instructions for external services
- You create accounts while I build the code
- We integrate everything together
